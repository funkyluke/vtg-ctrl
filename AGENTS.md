# AGENTS — Coordination Contract for VTG-Ctrl

Ground rules for any agent/session working on this repo. **Read this file first,
and check git state, before touching anything.** This is the single shared
coordination surface for multiple concurrent sessions.

## 1. Source-of-truth order

When deciding what a design *is*, resolve in this order:

1. `git status` / `git log` — is the file already dirty or diverged?
2. `docs/<subsystem>.md` — the intended design (human-readable)
3. the actual `.SchDoc` / `.asc` — final say; docs can be wrong

If a doc disagrees with a file, the **file wins**, and the disagreement must be
flagged in the doc (or fixed) in the same session — never silently papered over.

## 2. Binary file ownership

`.SchDoc`, `.PcbDoc`, `.BomDoc`, `.xlsx` are **binary and unmergable**. They:
- are edited by **one session at a time only**;
- must be **committed before the owning session switches tasks** (so the next
  session starts from a defined baseline);
- are **never** edited blindly when `git status` shows them dirty.

Claim a binary before working on it (a purposeful commit or a note in the
subsystem doc), and commit it before moving on.

## 3. Design decisions go in `docs/decisions/`

One file per real decision: `docs/decisions/DDD-NNN-<slug>.md` containing:

```
# DDD-NNN — <Title>
- Date / authoring session:
- Change:
- Why:
- Values / parameters:
- Status: (Proposal | Decided | Superseded)
```

Link every decision from the relevant subsystem page and from `docs/Main.md`'s
decision log. `Decided` is the state that authorises implementation.

## 4. Session handoff ritual

Finish a task with all three, in order:
1. `git commit` with a descriptive message (what + why);
2. update the relevant `docs/` subsystem page;
3. if the doc now disagrees with the file, say so in the file text.

**Ship state, not just work.** A session that ends without committing +
doc-updating has not finished.

## 5. LTspice scratch

- `LPF.asc` is **source** — track it (edit via ltspice-mcp-bridge).
- Generated outputs from simulation (`*.raw`, `*.net`, `*.log`, `*.op.raw`)
  are **scratch** — gitignored, not committed.
- Throwaway prototype files (e.g. `LPF_reordered.*`) are deleted once the
  real design supersedes them.
